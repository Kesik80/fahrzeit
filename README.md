# 🚗 Fahrzeit Rechner

Веб-приложение для расчёта времени в пути и генерации сообщения водителя карпула.

**Прод:** [fahrzeit.vercel.app](https://fahrzeit.vercel.app)

---

## 📱 Что это

Мобильное PWA, которое помогает водителю бригады:

- составить список пассажиров в нужном порядке подбора;
- рассчитать время выезда и прибытия к каждому;
- получить готовый текст для мессенджера и ссылку на маршрут в Google Maps.

Рассчитано на телефон, ставится на домашний экран.

## ✨ Возможности

### Главная страница

- **Профили по водителю.** Выбор себя в «Начальной точке» подгружает сохранённый список; данные каждого профиля лежат отдельно в `localStorage`.
- **Список участников** с субучастниками (несколько человек с одного адреса) и Treffpunkt (сбор в точке встречи).
- **Перетаскивание** для изменения порядка подбора.
- **Расчёт через Google Maps** — кнопка у каждого участника считает реальное время с учётом пробок. После расчёта иконка становится цветной, при ручной правке гаснет.
- **Долгое нажатие** на кнопку расчёта всех времён округляет их до 5 минут.
- **Генерация сообщения**: `19:45 Anatolii`, `19:55 Vasyl (+ Alex)`, `20:10 René (Rathaus Osterfeld)`.
- **Маршрут** в Google Maps со всеми остановками, «туда» и «обратно».
- **Сокращение ссылок** через Bitly или собственный `fhr.pp.ua`.
- **Тёмная и светлая тема**, сохраняется между запусками.
- **Виброотклик** на кнопки, вкладки и чекбоксы: короткий тап 10 мс, удаление 20 мс, долгое нажатие 30 мс, отказ 200 мс. Работает и на главной, и в редакторе.

### Редактор

- Девять разделов: участники, станции, времена, Treffpunkt, Treff-времена, порядок остановок, приветствия, конечные точки, прощания.
- **Проверка данных** — девять диагностик: точки без координат, дубли координат, времена-сироты, недостающие пары, ссылки на удалённых людей. У части есть кнопка автоисправления.
- **Координаты**: ввод числами, немецкой записью через запятую, градусами, ссылкой Google Maps или выбором точки на карте. Хранятся строго с шестью знаками после запятой.
- **Перетаскивание и сортировка** — по алфавиту, по дате добавления, по значению времени. Порядок сохраняется в файл.
- **Отмена** последних 25 действий.
- **Загрузка на GitHub** прямо из редактора, коммит делает серверная функция.

## 🔐 Вход в редактор

Пароль проверяется на сервере, в браузер не попадает. После первого успешного входа пароль запоминается на устройстве, и предлагается привязать отпечаток пальца через WebAuthn — дальше вход по пальцу, пароль остаётся запасным путём.

**Важно про безопасность.** Пароль хранится в `localStorage` в открытом виде: после подтверждения пальцем его нужно чем-то отправить на сервер. Отпечаток защищает от постороннего, взявшего разблокированный телефон, но не от того, кто откроет DevTools. Для личного инструмента это осознанный размен. Строже — серверный токен сессии вместо хранения пароля.

## 📦 Формат `stations.js`

```js
// Реестр имён участников
const defaultCoords = {
  "Sergii": {lat: 51.530133, lng: 6.850858},
};

// Станции
this.stations = {
  "Essen West": {lat: 51.453927, lng: 6.979400},
};

// Время в пути между участниками, минуты
this.travelTimes = { "Sergii-Anatolii": 5 };

// Места встречи
this.treffpunkt = { "OLGA-Park": {lat: 51.500434, lng: 6.868634} };

// Время от места встречи до каждого участника
this.trefftravelTimes = { "OLGA-Park-Sergii": 10 };

// Порядок остановок каждого водителя
this.participantOrders = {
  "Sergii": [
    "Anatolii",
    {"main": "Vasyl", "subParticipants": ["Alex"]},
    {"treffpunkt": "OLGA-Park", "persons": ["Dima"]}
  ],
  // с попутчиками от стартовой точки:
  "Dima": {"startPassengers": ["Marvin"], "order": ["Sergii"]}
};

const defaultFarewellData = { text: "Tschüss 👋", list: ["Tschüss 👋"] };
const defaultGreetingsData = ["Moin zusammen"];
const defaultMachineDestinationsData = [
  { name: "an der Maschine", lat: 51.481780, lng: 7.137622 }
];

// Служебный блок редактора: даты добавления записей и отметки
// «время посчитано через Google». Главная страница его не читает.
const defaultEntryMetaData = { defaultCoords: {}, stations: {}, treffpunkt: {}, times: {} };
```

**Соглашения.**

- Координаты — ровно 6 знаков после запятой (≈11 см). Редактор приводит к этому виду при загрузке.
- Время `1` — заглушка «ещё не считали». Пятиминутка это нормальное реальное значение, поэтому заглушкой она быть не может.
- Ключи времён — `"Откуда-Куда"`. Имена могут содержать дефис, разбор идёт по списку известных имён.

## ☁️ Serverless-функции

| Путь | Назначение |
|---|---|
| `/api/calculate-time` | Время в пути через Google Distance Matrix, с учётом пробок |
| `/api/maps-key` | Отдаёт ключ Google Maps для интерактивной карты |
| `/api/parse-coords` | Разворачивает короткие ссылки Google Maps и достаёт координаты |
| `/api/check-password` | Проверяет пароль редактора |
| `/api/upload-stations` | Коммитит `stations.js` в GitHub |
| `/api/bitly` | Сокращает ссылку через Bitly |
| `/api/expand` | Разворачивает короткие ссылки. Заменён на `parse-coords`, оставлен для совместимости |

## 🚀 Деплой

Vercel, функции из `/api` подхватываются автоматически.

Переменные окружения (Settings → Environment Variables):

```
GOOGLE_MAPS_API_KEY   ключ Google Maps (принимается и GOOGLE_API_KEY)
REDAKTOR_PASSWORD     пароль входа в редактор
UPLOAD_PASSWORD       пароль выгрузки stations.js на GitHub
GH_TOKEN              GitHub Personal Access Token, scope repo
GH_OWNER              владелец репозитория, напр. Kesik80
GH_REPO               имя репозитория, напр. fahrzeit
GH_FILE               файл для записи, по умолчанию stations.js
BITLY_ACCESS_TOKEN    токен Bitly для сокращения ссылок
```

`REDAKTOR_PASSWORD` и `UPLOAD_PASSWORD` **имеет смысл держать одинаковыми**: редактор запоминает пароль после входа и переиспользует его при выгрузке. Если значения разные, выгрузка будет отвечать 401 и каждый раз просить пароль заново.

**Ключ Google Maps.** `/api/maps-key` отдаёт его с `Access-Control-Allow-Origin: *`, то есть забрать может любой сайт. Ограничение задаётся не кодом: в Google Cloud Console нужно поставить HTTP-referrer restriction на `fahrzeit.vercel.app`.

## 🧭 Как вести разработку

Разработка ведётся с телефона, DevTools нет — поэтому:

- `console.js` подключён в конце `<body>` на всех страницах и рисует консоль поверх приложения. **Не удаляйте эту строку.**
- Правки `html`/`js` подхватываются сразу: service worker для них работает «сеть, откат в кэш».
- При изменении списка `CORE` в `sw.js` поднимайте номер в `CACHE`, иначе старый кэш останется жить.
